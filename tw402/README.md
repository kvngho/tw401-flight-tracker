# TW0402 · 파리 → 인천 귀국편

기존 TW401 앱의 화면과 기능을 유지한 별도 오프라인 PWA입니다. 출국편의 파일, URL, 캐시는 변경하지 않습니다.

## 일정
- 파리 CDG 출발: 2026년 10월 10일 20:30 CEST (UTC+2)
- 인천 ICN 도착: 2026년 10월 11일 15:40 KST (UTC+9)
- 예정 소요 시간: 12시간 10분
- 위탁수하물 23kg: 사용자가 제공한 예약 정보 표시이며 항공사 수하물 규정 조회 기능이 아닙니다

## iPhone에서 오프라인 준비
1. 인터넷이 있을 때 이 폴더의 `index.html` 또는 `TW402-flight-tracker.html`을 HTTPS 주소로 Safari에서 엽니다
2. ‘오프라인 준비 완료’를 확인합니다
3. 공유 → 홈 화면에 추가를 선택합니다
4. 추가된 귀국편 아이콘으로 다시 열고 준비 완료를 확인합니다
5. 출발 전에 비행기 모드로 전환한 후 앱을 완전히 닫고 다시 열어 테스트합니다

최초 저장에는 인터넷이 필요합니다. 사이트 데이터나 저장된 앱을 삭제하면 다시 저장해야 합니다. 페이지는 외부 지도·폰트·위치 API 없이 작동하며, 기기 시간을 자동으로 설정해야 합니다.

`TW402-flight-tracker.html` 하나에도 지도·스타일·코드가 들어 있습니다. HTML 열기를 지원하는 브라우저에서는 파일 단독으로 사용할 수 있습니다. iPhone 파일 미리보기는 JavaScript 실행을 보장하지 않으므로 홈 화면 앱 방식을 권장합니다. 설치에는 같은 폴더의 manifest, service worker, 아이콘이 함께 있어야 합니다.

## 지도 출처와 한계
- FlightAware TWB402, 파리 출발일 2026-10-04, 확인일 2026-10-06
- 원본: https://www.flightaware.com/live/flight/TWB402/history/20261004/1840Z/LFPG/RKSI/tracklog
- 10월 2일 기록에서도 같은 큰 남측 경로를 교차 확인했습니다. 화면 좌표는 10월 4일 기록만 사용합니다: https://www.flightaware.com/live/flight/TWB402/history/20261002/1840Z/LFPG/RKSI/tracklog
- 753개 실관측 위치에서 87개를 간추렸고, 제공자의 ‘Estimated’ 188개 위치는 제외했습니다
- 금색 점선은 여섯 관측 공백(최대 약 132분) 및 공항 좌표 연결의 구면 보간입니다. 그 구간의 실제 경로를 확인한 것으로 해석하면 안 됩니다
- 실선도 간추린 관측 좌표 사이의 연결이며 정확한 항공 항로도나 운항 계획이 아닙니다
- 10월 4일 경로가 10월 10일 운항 경로를 예측하거나 보장하지 않습니다
- 애니메이션은 예정 비행 진행률을 누적 경로 거리에 매핑합니다. 실제 위치·GPS·속도·지연·이륙·착륙 여부를 추적하지 않습니다
- 좌표 사실과 출처, 관측 공백은 `route-evidence.json`에 기록했습니다

## 검증
- 앱 자체 테스트 39개: UTC 경계, 12시간 10분, 날짜 변경, 파리 DST, 귀국편 방향, 좌표/지도 범위
- 원본 출국편 자체 테스트 23개 유지

루트의 GitHub Actions workflow가 위 검사를 수행하고 결과 및 스크린샷을 보관합니다. Chromium의 모바일 뷰포트 검사는 실제 iPhone Safari 설치 검사를 대체하지 않으므로 출발 전 비행기 모드 테스트가 필요합니다.
